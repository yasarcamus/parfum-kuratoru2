# Parfüm Küratörü

Parfüm Küratörü, kullanıcıların parfüm keşfetmelerine, listeler oluşturmalarına ve kişisel notlar almalarına olanak tanıyan modern bir web uygulamasıdır.

## Özellikler

*   **Parfüm Arama ve Filtreleme:** Koku türü, mevsim, cinsiyet ve kullanım alanına göre detaylı filtreleme.
*   **Kişisel Listeler:** Favoriler ve özel listeler oluşturma.
*   **Quiz:** Kullanıcının zevkine uygun parfüm önerileri sunan interaktif test.
*   **PWA Desteği:** Mobil cihazlara kurulabilir ve çevrimdışı çalışabilir.
*   **Kişisel Notlar:** Her parfüm için özel notlar alma.

## Kurulum

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyin:

1.  Depoyu klonlayın (veya indirin).
2.  Bağımlılıkları yükleyin:
    ```bash
    npm install
    ```

## Geliştirme

Geliştirme sunucusunu başlatmak için:

```bash
npm run dev
```

Tarayıcınızda `http://localhost:5173` adresine gidin.

## Build (Derleme)

Projeyi canlı ortam (production) için derlemek:

```bash
npm run build
```

Çıktılar `dist` klasöründe oluşturulacaktır.

## Test

Otomatik testleri çalıştırmak için:

```bash
npm test
```

## Teknolojiler

*   Vanilla JavaScript (ES Modules)
*   Vite (Build Tool)
*   Vitest (Testing)
*   CSS3 (Variables, Flexbox, Grid)
